# ProgressionLESS: Hospitality

**All the Progression goodness, less research.**

Overhauls and integrates hospitality mods into a more complete package.

The "LESS" is less research: Progression: Hospitality adds up to 3 research projects depending on your mods. Everything stays in the same era, and still needs the other research it did before.

Forked from [Progression: Hospitality](https://steamcommunity.com/sharedfiles/filedetails/?id=3265298940) by ferny. Huge thanks to ferny for the original mod and all the Progression work this builds on. For a really good modpack, check out [The Progression Modpack](https://steamcommunity.com/sharedfiles/filedetails/?id=3521297585).
